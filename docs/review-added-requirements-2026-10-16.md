# 新增需求复审记录（2026-10-16）

## 范围

Codex 默认负责人、Kimi Code CLI、DeepSeek 中转站配置与模型目录、密钥保存、官方闲时派活、模型图标和顶栏状态。

## 发现与处理

1. **闲时限制可被群聊续接和小队流程绕过**：已将判断收敛为公共策略，覆盖普通派活、任务唤醒、群聊续接和小队启动/后续轮次。
2. **HTTP 公网中转站会明文传输 API 密钥**：已强制公网地址使用 HTTPS，仅对 localhost、127.0.0.0/8 和 ::1 放行 HTTP。
3. **DeepSeek 保存与其他设置同时发生时可丢失密钥保存步骤**：已让并发保存共用并等待同一个 Promise，设置真正落盘后才保存密钥。
4. **法定节假日未按官方闲时处理**：已加入 2026 年官方休假日。未来年份在国务院公布后更新；未收录时保守按普通工作日处理。
5. **新增名单与 UI 规范测试未同步**：已更新 Kimi 选手、隔离模板、品牌变量与弹窗底部的规范用法及对应测试。

## 验收要点

- 高峰期任何入口均不能启动 DeepSeek，关闭开关后恢复全天可派。
- 周末和已登记的法定节假日全天可派。
- 公网 HTTP 地址被拒绝，本机 HTTP 可用。
- 设置并发保存时 DeepSeek 密钥登录只在配置落盘成功后执行。
