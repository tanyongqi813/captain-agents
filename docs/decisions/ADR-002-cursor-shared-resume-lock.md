# ADR-002：Cursor 群聊续接有限使用共享锁目录

- 状态：已接受
- 日期：2026-10-18
- 决策人：主人

## 背景

macOS 上的 `cursor-agent` 2026.10.14 在执行 `--resume` 时，把会话认领锁写死在 `/tmp/cursor-agent-persist-<uid>`；该位置不服从 `TMPDIR`、`CURSOR_CONFIG_DIR` 或 `CURSOR_DATA_DIR`。不允许写这个目录时，Cursor 可以完成群聊首轮，但不能续接同一会话。真实探针见 `docs/research/cursor-chat-resume-2026-10-17.md` 与 `docs/research/cursor-chat-resume-2026-10-18.md`。

这个目录属于当前 macOS 用户，供该用户的所有 `cursor-agent` 会话共用，不是每件任务独立目录。开放它会让受隔离的 Cursor 续接轮能够修改其他 Cursor 会话的锁，可能造成跨会话干扰、认领失败或拒绝服务；现有证据没有表明仅凭这些锁即可读取其他会话正文，但不能据此承诺未来版本也不会扩大用途。

## 决定

主人接受上述残余风险，以换取 Cursor 在项目群聊中保留上下文并续接同一会话。安全例外必须同时满足：

1. 只用于 macOS 上的 Cursor 项目群聊续接轮；普通 Cursor 派活、非群聊任务、群聊首轮、其他选手和 Windows 不获得该写权限。
2. 只开放 `/tmp/cursor-agent-persist-<uid>` 及其在 macOS 上对应的真实路径，不开放 `/tmp`、`/private/tmp` 或其他公共临时目录。
3. 开放前确认目录是当前用户所有的普通文件夹、不是符号链接，权限为 `0700`；解析到意外真实路径时拒绝运行。
4. 任务清理只可清理能确认属于当前会话的锁；不得删除共享根目录，不得清理其他会话的锁。
5. 共享目录例外不得绕过现有登录、额度、主人设置、网络、只读工作区、全局配置禁写或平台准入。
6. Cursor 版本、锁目录位置或目录结构变化时，默认停止群聊续接并要求重新探针；不能自动扩大路径。

## 回退

若出现其他 Cursor 会话被干扰、目录校验失败、版本变化后探针不通过或无法证明权限仍然最小，应撤销续接轮的共享目录写权限，恢复核心与界面对 Cursor 群聊成员的禁用，直到新的安全方案通过评审。

## 影响

- Cursor 群聊可以保持上下文并完成多轮交接。
- 同一用户的其他 Cursor 会话可能受到锁文件干扰，这是主人明确接受的有限风险。
- 该决定不授权为所有 Cursor 任务静态开放共享目录，也不授权开放 Cursor 小队搭档或 Windows Cursor。
