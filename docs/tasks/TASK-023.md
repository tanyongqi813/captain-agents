# TASK-023：负责人切换与诊断角色澄清

- 状态：`PASSED`
- 优先级：`P1`
- 难度等级：`Medium`
- 前置任务：`TASK-022` 已通过
- 需求来源：设置页未说明“接入 AI”只配置负责人提醒；切换负责人步骤不明确；无人看守的临时诊断选手也被称为“负责人 AI”，导致额度通知含义混淆。

## 业务结果

主人能明确区分负责人、执行者和自动故障诊断三种角色。负责人可从 Codex 切换为 Claude 等其他 AI，不改变在跑任务，也不用重新配置执行者提示词；新负责人按持久状态接班。

## 验收标准

1. 接入页说明可提前接入多位潜在负责人，切换时不撤下旧接入。
2. 首次接入说明和指挥手册给出 `guide`、`inbox`、`status` 三步接班流程，并说明旧聊天中未落盘判断不会自动搬运。
3. 用户可见的无人看守原因把临时只读诊断选手与对话负责人区分开，额度耗尽时明确不是负责人会话掉线。
4. 执行者共同规则和模型适配仍由每个 job 自动附加，无需主人配置。

## 实施报告

- 更新负责人常驻规则、首次接入说明、设置页和指挥手册，补齐无破坏切换语义。
- 将无人看守用户可见文案中的“负责人 AI”改为“自动故障诊断选手/故障诊断 AI”。
- 协作页不再用 Claude 图标冒充负责人身份，改为不绑定厂商的“主”标识。
- 保留既有持久记录、隔离、额度和派发行为，不新增隐式负责人所有权或自动搬运聊天内容。
