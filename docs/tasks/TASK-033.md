# TASK-033 — 每日预估金额账本与双阈值

## 业务结果

按手工人民币单价和实际 token 统计每日预估花费，为跨项目共享预算提供可审计账本。

## 非目标

- 不查询第三方账单、不自动发起收费探测、不承诺实际账户绝不超额。
- 不在规划阶段修改实现或启动真实选手。

## 架构设计

新增独立金额设置与带锁原子账本，复用现有成本设置能复用的解析但不混淆套餐百分点。价格按连接预算组与实际模型 ID 配置，输入未命中、缓存读取、输出按元/百万 token 分开；缓存写入有独立字段时单列，没有时按输入价保守计，不重复计费。所有金额使用明确精度的整数或十进制定点；拒绝负数、NaN、无穷。软预算小于等于上限。按 Asia/Shanghai 日界、观测时间分段归账；最终累计量仅结算新增差值，重放/恢复幂等；跨日不能把全部用量算到结束日，无法归属部分明确标未知。价格、模型与计费口径随执行快照冻结，新价格不改历史账。连接组跨项目共享，编辑地址/模型不能重置今日账，多个独立账户由显式本地预算组区分。

## 兼容要求

- 保留旧设置和历史记录可读；新字段不能静默降低现有安全约束。
- CLI 与桌面共用核心规则；任务执行不改写规划文档。

## 验收标准

1. 已知 token 样例金额正确，缓存包含/不包含输入的通道差异归一，重复事件不重复入账。
2. 软阈值、上限、无用量、并发原子预留、跨日、改价、改连接和恢复均有确定性测试。
3. 未观测用量不补零；账本明确区分已结算、预留和未知，保留来源与原因。
