## 业务结果

编辑、选手列表、管理模型和新任务记录显示同一实际模型 ID，解决保存模型与内置名称不一致。

## 非目标

- 不查询第三方账单、不自动发起收费探测、不承诺实际账户绝不超额。
- 不在规划阶段修改实现或启动真实选手。

## 架构设计

按连接标识（规范化地址、协议和本地凭据版本，不含密钥）保存模型目录缓存；编辑获取模型和管理模型共用目录。保存后的 Pro/Flash 是稳定槽位，展示槽位名与实际 ID；任务创建时冻结真实 ID，运行、用量和成本均使用该快照。刷新发现已选 ID 消失时标为不可用并阻止新派发，保留配置供纠正，禁止静默换模型。自动刷新只在既有授权的模型查询通道内运行，限频、超时、失败保留最后成功目录并标陈旧；更换地址后不可复用旧目录或向新地址隐式发送旧凭据。

## 兼容要求

- 保留旧设置和历史记录可读；新字段不能静默降低现有安全约束。
- CLI 与桌面共用核心规则；任务执行不改写规划文档。

## 验收标准

1. 编辑保存后管理模型、选手列表和新任务真实 ID 一致，历史任务身份不改写。
2. 目录获取持久化；重复刷新、离线、模型下线、地址改变和凭据更新均有替身验证。
3. 自动刷新不触发推理请求、不自动更换已选模型、不自动改价格。
