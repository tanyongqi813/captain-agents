## 业务结果

负责人接收当前执行胶囊、实现报告、改动摘要、活动、验证和剩余预算组成的有界证据包；回包只允许五种固定动作，并绑定当前候选和胶囊版本。

## 非目标

- 不启动模型、不访问凭据、不改既有自治运行状态或选手配置。
- 不把修正或拆分提案当可执行提示词，不在本切片生成或派发增量胶囊。

## 架构设计

纯函数模块构造版本化证据包，复用已有脱敏规则；当前胶囊不静默截断，其他证据分段限长并显式标记省略。回包有独立标记，严格校验字段、长度、动作专属字段、候选哈希和胶囊指纹。修正/拆分只返回待编译提案，后续由平台从原边界生成增量胶囊并校验后才能执行。

## 兼容要求

- 不改变既有诊断协议与旧自治记录的读取行为。
- 不嵌入供应商、模型、权限、命令或网络配置。

## 验收标准

1. 完成、失败、验收失败和主动中断均能生成相同六类证据结构；缺证据显示未知。
2. 证据有长度上限、路径与常见凭据脱敏；完整胶囊超限直接拒绝，不截掉边界。
3. 只接受 accept、correct、handoff、split、owner；拒绝未知/重复/越权字段、格式错、版本错及过期候选。
4. correct/split 只产生不可直接派发的提案；不混用旧诊断动作。
5. 全部测试离线，证明函数不修改输入、不读写文件或启动进程。

## 依赖与排序

- 前置 TASK-025；本任务是 TASK-027 的协议前置切片。TASK-027 负责后续持久记录、受信负责人接线与增量胶囊，不因底座通过而自动开放无人看守。
