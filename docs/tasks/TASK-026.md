## 业务结果

主人可以对一个或多个已登记项目显式开启有限自动队列；工作台只领取契约完整的 READY Capsule。同一项目内依赖已满足且写入范围可证明不冲突的多个任务可并行；跨项目继续按授权、优先级、公平性、总并发和预算推进。

## 验收标准

1. 默认关闭；打开应用、登记项目或发现 READY 都不会自行花额度。
2. 授权明确记录项目范围、并发数、预算、写手/审查者范围和停止条件。
3. 跨项目公平领取；同一任务不重复启动；任务状态变化后重新权威校验。
4. 完成不等于合并；负责人评审和规划状态更新后才解锁后续任务。
5. 额度、登录、隔离、契约或验证异常时有界停止并交给主人。
6. 项目内只在依赖图允许且 Capsule 文件白名单、生成输出和必要共享资源都不冲突时并行；无法证明时串行。
7. 不同能力画像的 READY 任务可分配给不同执行者，单任务回退顺序不会让某位执行者永远得不到初始任务。
