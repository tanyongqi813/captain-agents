# TASK-026：多项目授权队列自动领取

- 状态：`DRAFT`
- 优先级：`P1`
- 难度：`High`
- 前置任务：`TASK-025` 评审为 `PASSED` 或 `PASSED_WITH_NOTES`

## 业务结果

主人可以对一个或多个已登记项目显式开启有限自动队列；工作台只领取契约完整的 READY Capsule，按依赖、优先级、并发和预算推进，替代手工复制下一条开发指令。

## 验收标准

1. 默认关闭；打开应用、登记项目或发现 READY 都不会自行花额度。
2. 授权明确记录项目范围、并发数、预算、写手/审查者范围和停止条件。
3. 跨项目公平领取；同一任务不重复启动；任务状态变化后重新权威校验。
4. 完成不等于合并；负责人评审和规划状态更新后才解锁后续任务。
5. 额度、登录、隔离、契约或验证异常时有界停止并交给主人。

## 前置任务

等待 TASK-025 通过后形成精确执行胶囊。
