## 业务结果

确认无界面执行是否发生启动无响应或工具读取未结束，建立可重复、有限成本的诊断基线。

## 非目标

- 不修复 IDE 扩展、不重启 Extension Host、不无限自动重试。
- 不在本轮规划阶段运行收费探测或改实现。

## 架构设计

新增独立诊断脚本（路径执行前确认）在临时仓库写入固定小文件，要求只读取该文件并返回短校验结果。先离线替身，再人工触发一次真实探测；每次总时限 90 秒、最多一次模型会话、不续接不重试，超时停止且回收本探测进程树。记录版本、实际模型 ID、启动/首个结构化事件/工具开始结束/结果/退出时间与退出码；没有事件不能诊断为读取卡死。不给出频率结论，频率需要多次独立授权样本与失败分母。

## 兼容要求

- 既有隔离、凭据、网络和预算边界保持；执行与 IDE 的进程证据分开。
- 历史记录未采集字段显示未知，不补零。

## 验收标准

1. 不联网替身覆盖成功、无输出、只有开始、进程不退出和超时清理。
2. 真实探测为单独手动动作，不从启动应用、定时器或测试自动触发；报告明确实际用量未知与金额未设硬限额。
3. 采样不读取真实项目业务文件、不重启 IDE 或 Extension Host；日志脱敏并限制大小。
